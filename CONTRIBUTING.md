# pyRBM roadmap

Initial work to bring pyRBM into a beta release will mostly consist of developing the core framework fundementals.

Work in development at this stage includes:

- [ ] An event queue to enable determinstic events triggered at a precise time (either a certain date, or at a certain frequency).
- [ ] Trajectory saving and checkpointing
- [ ] Support for multiple parallel simulations via multiprocessing.
- [ ] The timestepping Gillespie algorithm to perform exact simulation with respect to deterministic events.

Then development work will add new simulation algorithms, examples and ensure more rigourous testing. The success of this step hinges on the contribution and input from the broader modelling community. Contributions of ideas, simulation algorithms and examples are extremely welcome.
